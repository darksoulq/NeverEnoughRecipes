Commands and Permissions

Never Enough Recipes provides a streamlined set of commands for players to access the interface and for administrators to manage the plugin.

Commands

All commands are prefixed with /ner.

Command

Description

Required Permission

/ner

Opens the Main Menu of the recipe browser.

ner.open_gui

/ner config

Opens the Controls Menu, allowing players to map their personal keybinds for viewing recipes and usages.

ner.open_gui

/ner reload

Reloads all plugin registries, item groups, and third-party integrations without requiring a server restart.

ner.reload

Running /ner or /ner config will automatically save a background backup of the player's inventory before masking their screen with the GUI, ensuring no items are lost if the server stops unexpectedly.

Permissions

All permission nodes fall under the ner namespace.

Node

Default

Description

ner.open_gui

true

Allows a player to open the recipe browser and access their configuration menu. Granted to all players by default.

ner.reload

op

Allows administrators to run the reload command. Granted only to server operators by default.
